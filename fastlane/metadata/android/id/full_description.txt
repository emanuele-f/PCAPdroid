<i>PCAPdroid</i> adalah aplikasi sumber terbuka yang ramah privasi yang dapat melacak, menganalisis, dan memblokir koneksi yang dibuat oleh aplikasi lain di perangkat.
Aplikasi ini juga dapat mengekspor PCAP dump dari lalu lintas, memeriksa permintaan HTTP, mendekripsi lalu lintas TLS, dan banyak lagi.

PCAPdroid mensimulasikan VPN untuk menangkap lalu lintas jaringan tanpa perlu akses root. Ini tidak menggunakan server VPN jarak jauh, sebaliknya data diproses secara lokal di perangkat.

<b>Fitur utama:</b>

* Merekam dan menganalisis koneksi yang dibuat oleh aplikasi pengguna dan sistem
* Dapatkan ringkasan berapa banyak data yang dikirim dan diterima setiap aplikasi
* Penggunaan baterai rendah, untuk perekaman terus-menerus sepanjang hari
* Ekstrak host dan alamat IP dari DNS, TLS, dan HTTP
* Rekam lalu lintas ke file PCAP dengan metadata aplikasi tambahan
* Kirim lalu lintas melalui PCAP-over-IP untuk analisis waktu nyata (misalnya di Wireshark)
* Mendekripsi lalu lintas HTTPS/TLS, ekstrak URL, dan simpan SSLKEYLOGFILE
* Periksa permintaan/balasan HTTP dan ekspor ke HAR
* Identifikasi negara dan ASN dari server jarak jauh melalui pencarian database offline
* Pada perangkat yang sudah di-root, tangkap lalu lintas saat aplikasi VPN lain berjalan

Jika Anda berencana menggunakan PCAPdroid untuk melakukan analisis paket, cek <a href='https://emanuele-f.github.io/PCAPdroid/quick_start#14-packet-analysis'>bagian khusus</a> pada manual.
