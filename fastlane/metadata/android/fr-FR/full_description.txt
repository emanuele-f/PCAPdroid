<i>PCAPdroid</i> est une application open source respectueuse de la vie privée qui permet de suivre, d'analyser et de bloquer les connexions établies par les autres applications de l'appareil.
Elle peut également exporter une capture PCAP du trafic, inspecter les requêtes HTTP, déchiffrer le trafic TLS et bien plus encore.

PCAPdroid simule un VPN afin de capturer le trafic réseau sans root. Il n'utilise pas de serveur VPN distant ; les données sont au contraire traitées localement sur l'appareil.

<b>Principales fonctionnalités :</b>

* Journaliser et analyser les connexions établies par les applications utilisateur et système
* Obtenir un récapitulatif des données envoyées et reçues par chaque application
* Faible consommation de batterie, pour une capture continue toute la journée
* Extraire les hôtes et les adresses IP depuis DNS, TLS et HTTP
* Enregistrer le trafic dans des fichiers PCAP avec des métadonnées d'application supplémentaires
* Envoyer le trafic via PCAP-over-IP pour une analyse en temps réel (par ex. sur Wireshark)
* Déchiffrer le trafic HTTPS/TLS, extraire les URL et enregistrer le SSLKEYLOGFILE
* Inspecter les requêtes/réponses HTTP et les exporter au format HAR
* Identifier le pays et l'ASN du serveur distant grâce à des recherches dans des bases de données hors ligne
* Sur les appareils rootés, capturer le trafic pendant que d'autres applications VPN sont en cours d'exécution

Si vous envisagez d'utiliser PCAPdroid pour effectuer une analyse de paquets, consultez <a href='https://emanuele-f.github.io/PCAPdroid/quick_start#14-packet-analysis'>la section spécifique</a> du manuel.
