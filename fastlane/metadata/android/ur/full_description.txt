<i>PCAPdroid</i> ایک پرائیویسی دوست ایپ ہے جو آپ کو اپنے آلے میں موجود دیگر ایپس کے بنائے گئے کنکشنز کو ٹریک اور تجزیہ کرنے کی سہولت دیتی ہے۔
یہ آپ کو ٹریفک کا PCAP ڈمپ ایکسپورٹ کرنے، HTTP کا معائنہ کرنے، TLS ٹریفک کو ڈکرپٹ کرنے اور بہت کچھ کرنے کی اجازت بھی دیتی ہے۔

PCAPdroid بغیر روٹ کے نیٹ ورک ٹریفک کیپچر کرنے کے لیے VPN کی نقل تیار کرتی ہے۔ یہ کوئی ریموٹ VPN سرور استعمال نہیں کرتی؛ بلکہ ڈیٹا آلے پر مقامی طور پر پروسیس کیا جاتا ہے۔

<b>خصوصیات:</b>

* صارف اور سسٹم ایپس کے بنائے گئے کنکشنز کو لاگ اور جانچیں
* SNI، DNS کوئری، HTTP URL اور ریموٹ IP ایڈریس نکالیں
* بلٹ اِن ڈیکوڈرز کی بدولت HTTP درخواستوں اور جوابات کا معائنہ کریں
* کنکشنز کے مکمل پے لوڈ کو ہیکس ڈمپ/ٹیکسٹ کے طور پر جانچیں
* HTTPS/TLS ٹریفک کو ڈکرپٹ کریں اور SSLKEYLOGFILE ایکسپورٹ کریں
* ٹریفک کو PCAP فائل میں ڈمپ کریں، براؤزر سے ڈاؤن لوڈ کریں، یا ریئل ٹائم تجزیے کے لیے ریموٹ ریسیور پر اسٹریم کریں (مثلاً Wireshark)
* اچھی ٹریفک کو فلٹر کر کے بے قاعدگیوں کو آسانی سے پہچاننے کے لیے قواعد بنائیں
* آف لائن ڈیٹابیس تلاش کے ذریعے ریموٹ سرور کا ملک اور ASN شناخت کریں
* روٹ شدہ آلات پر، دیگر VPN ایپس چلنے کے دوران ٹریفک کیپچر کریں

اگر آپ پیکٹ تجزیہ کرنے کے لیے PCAPdroid استعمال کرنے کا ارادہ رکھتے ہیں، تو براہ کرم دستی کا <a href='https://emanuele-f.github.io/PCAPdroid/quick_start#14-packet-analysis'>مخصوص سیکشن</a> دیکھیں۔
