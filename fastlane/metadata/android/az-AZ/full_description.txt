<i>PCAPdroid</i> cihazınızdakı digər tətbiqlərin qurduğu əlaqələri izləməyə və təhlil etməyə imkan verən məxfiliyə hörmətlə yanaşan tətbiqdir.
O, həmçinin trafikin PCAP dempini ixrac etməyə, HTTP-ni yoxlamağa, TLS trafikini deşifrə etməyə və daha çox şeyə imkan verir.

PCAPdroid şəbəkə trafikini root olmadan tutmaq üçün VPN simulyasiya edir. O, uzaq VPN serverindən istifadə etmir; bunun əvəzinə məlumatlar cihazda lokal olaraq emal olunur.

<b>Xüsusiyyətlər:</b>

* İstifadəçi və sistem tətbiqlərinin qurduğu əlaqələri qeydə alın və nəzərdən keçirin
* SNI, DNS sorğusu, HTTP URL və uzaq IP ünvanını çıxarın
* Daxili dekoderlər sayəsində HTTP sorğu və cavablarını yoxlayın
* Əlaqələrin tam yükünü heksdemp/mətn şəklində yoxlayın
* HTTPS/TLS trafikini deşifrə edin və SSLKEYLOGFILE ixrac edin
* Trafiki PCAP faylına yazın, brauzerdən endirin və ya real vaxt təhlili üçün uzaq qəbuledici cihaza ötürün (məsələn, Wireshark)
* Yaxşı trafiki süzgəcdən keçirmək və anomaliyaları asanlıqla aşkar etmək üçün qaydalar yaradın
* Oflayn verilənlər bazası axtarışları vasitəsilə uzaq serverin ölkəsini və ASN-ni müəyyən edin
* Rootlanmış cihazlarda digər VPN tətbiqləri işləyərkən trafiki tutun

PCAPdroid-dan paket təhlili aparmaq üçün istifadə etməyi planlaşdırırsınızsa, lütfən, təlimatın <a href='https://emanuele-f.github.io/PCAPdroid/quick_start#14-packet-analysis'>müvafiq bölməsinə</a> baxın.
